# Dataset card preparation — no dataset published yet

Use the organiser's actual dataset template:
https://huggingface.co/datasets/HackApertus/online_hack_template

Complete from verified artifacts before publication:

- Dataset name, version, authors and public Hugging Face URL.
- Defined Swiss use case, intended users and exclusions.
- Languages, question count, topic coverage and descriptive statistics.
- Evaluation questions, accepted answer variations and source citations.
- Raw model responses linked to question IDs and model/run identifiers.
- Metadata: provenance, source-level licences, dates and applicable consent information.
- Construction and annotation process, real reviews and quality checks.
- Training/development/test separation and contamination checks actually performed.
- Judge setup, human-audit coverage and judge–human agreement.
- Known errors, coverage limits, intended uses and inappropriate uses.
- CDLA-Permissive-2.0 licensing, subject to confirmed rights for included material.

Do not publish synthetic examples as actual evidence, private client documents, personal information, secrets or data with unresolved redistribution rights.
